Cách tải dự án về máy
1. Cài Git và Visual Studio 2022.
2. Mở Terminal hoặc Git Bash.
3. Chạy lệnh git clone theo URL repository.
4. Mở thư mục dự án vừa clone.
5. Mở file .sln bằng Visual Studio 2022.
6. Chọn đúng cấu hình và nhấn F5 để chạy.
